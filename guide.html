📖 كيف تستعمل الموقع

دليل سريع · Guide rapide

🚀 إرسال

  1. افتح الموقع واضغط ✨ إنشاء رمز.
  2. اختر ملفاتك (من منطقة السحب، زر 📁 مجلد، 📄 ملفات، أو 📷 صور).
  3. أعطِ الرمز لصديقك أو انسخ 🔗 Lien وأرسله.
  4. عندما يصبح المستقبِل مستعدًا، يظهر زر 📤 إرسال الملفات — اضغطه.

📥 استقبال

  1. افتح الموقع ثم 📥 استقبال.
  2. اكتب الرمز الذي وصلك، ثم 🔗 اتصال.
  3. في كل ملف ستجد خيار تنزيله (أو فتحه إذا كانت صورة).

💬 الدردشة

  1. افتح صفحة 💬 دردشة، ثم ✨ إنشاء رمز دردشة.
  2. أرسل الرمز لصديقك ليدخله مرة واحدة.
  3. كتبوا بأدمنية، وابعث الصور بزر 📷.
  4. المحادثة مشفّرة (AES-GCM) ولا تُحفظ.

🌐 عبر الإنترنت

  • الموقع يعمل عبر الإنترنت: الدول المختلفة يمكنها الإرسال والتلقّي.
  • أخرج VPN إذا كان مفعّلًا، فهو يبطئ الاتصال.
  • نفس الشيء PC↔PC أو PC↔هاتف أو هاتف↔PC.
